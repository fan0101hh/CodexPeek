# 动态账号展示调整

用户已明确要求：发现几个账号就展示几个，当前使用的账号始终排第一。

- 账号按稳定 ID 去重；当前账号第一，其余按稳定 ID 排列，改名不影响顺序。过期账号仍展示状态，删除账号不留空位。
- 移除双账号选择界面；旧选择设置只作迁移兼容，别名、透明度、路径和刷新设置保留。
- 保持 212 pt 宽度，窗口按行数增高并保持顶部位置；超过当前屏幕可用高度时滚动展示，不截掉账号。
- 所有展示账号参与刷新，最多三个并发查询；按到期时间公平调度，继续遵守单账号退避。账号较多时实际刷新周期可能大于设置间隔。
- 测试空列表、多账号、去重、当前账号切换、删除、旧选择无效及窗口高度边界；打包 0.1.2 通用应用并校验签名。
- 不申请电脑使用权限；真实桌面尺寸与滚动交互仍需手工验收。

## 后续用户调整（0.1.3）

用户要求未登录账号不展示，新增对空授权、过期和服务确认授权失败的过滤，网络及限流仍保留展示。显示列表作为可观察状态驱动窗口高度，凭据更新后重新判定。用户反馈拖动不直观，新增顶部原生拖动条，保留账号行点击行为；详情中的账号名使用明确输入框。
