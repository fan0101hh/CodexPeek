## 0.1.1 透明背景调整

移除 SwiftUI 深色毛玻璃，改用明确的 alpha 底色；设置中提供背景透明度滑块。窗口及 hosting view 均声明非不透明，并关闭窗口阴影。新增旧设置迁移检查，确认升级保留账号别名、账号选择与自定义路径。核心检查通过；桌面合成后的实际视觉效果仍未进行 GUI 验收。

## 0.1.2 动态账号列表

20 项核心检查通过；覆盖全部账号展示、当前账号优先、去重、切换与删除、旧选择不再筛选、新旧偏好兼容和屏幕高度上限。窗口与详情均使用完整排序列表。刷新最多三个并发，并按到期时间轮转。桌面窗口实际增减、滚动及跨屏交互仍未进行 GUI 验收。

## 0.1.3 登录过滤及拖动入口

新增未登录、过期及授权失败隐藏规则；网络异常与限流保留展示。新增到期边界与重新恢复的核心检查，23 项核心检查全部通过。顶部加入独立原生拖动条，账号别名改为明确的输入框。实际桌面拖动尚未验收，不将编译成功等同于交互验证。
