# 凭据处理

- 只读取用户明确配置的两处文件，不扫描用户目录，不读取聊天内容、工具数据库或会话历史。
- 只使用 access_token；不向令牌刷新端点发请求，不修改共享 refresh_token 或原始认证文件。
- 授权仅通过 HTTPS Authorization 请求头发送至固定的 `chatgpt.com` 用量路径，不出现在命令行、URL、日志或错误消息中。
- 使用系统证书验证，不提供忽略证书错误的开关。拒绝 HTTP 重定向，不允许令牌跟随跳转。
- ephemeral URLSession 关闭 URL 缓存、Cookie 存储和凭据存储；应用不主动落盘认证数据或服务响应。
- UserDefaults 只保存非认证设置；账号 ID、别名和路径仍属于个人信息，不应提交自己的偏好文件。
- 无遥测、分析 SDK 或自动错误上传。诊断命令只输出账号数量、匿名序号和数据是否可用。
- 本应用没有沙盒发行配置，和其他本地应用一样受 macOS 用户权限约束。内存中的令牌仍可能受本机恶意进程、系统交换或崩溃采集影响，不承诺绝对保密。

停用时通过菜单栏退出即可停止读取和请求。应用未创建新令牌或 Keychain 项；如需撤销已有账号授权，请通过原登录工具或账号安全设置处理。删除设置可使用 macOS 的 `defaults delete local.codexpeek.app`（删除前确认确实不再需要账号别名及窗口位置）。
