# CodexPeek

一个轻量的 macOS 原生悬浮窗，用来快速查看 Codex 订阅账号的剩余额度。

当前版本专注多账号额度展示；代码将数据来源、查询、刷新和界面分开，后续可扩展其他信息。个人项目，无商业服务；公开源码不表示授予自由使用、修改或分发的许可，项目目前未添加许可证。

## 功能

- 默认 300 pt 宽的透明悬浮窗，随账号数量增高；右下角可拉宽、拉高并记住尺寸，内容超出时滚动展示。默认背景透明度 85%，可调至完全透明。
- 每个账号两条方形额度条，参考 Codex 的实心段与点阵样式：实心表示剩余，点阵表示已用，右侧显示剩余百分比与重置时间。
- 展示所有具有可用登录授权的账号，当前账号始终排第一；支持自定义别名。
- 悬浮窗只展示，不响应账号点击；悬停查看提示，账号改名和设置从菜单栏“账号与设置…”进入，面板从菜单栏图标下方展开，不依附悬浮窗；隐藏悬浮窗也能打开设置。
- 默认每 5 秒查询，支持 10、30 秒；失败退避，休眠暂停、唤醒刷新。
- 按住顶部短线移动窗口，拖动右下角改变宽度和高度；自动保存位置与尺寸，支持置顶和菜单栏隐藏。
- 专用应用图标与双进度条菜单栏图标；默认以菜单栏模式运行，不占用 Dock。
- 不依赖 Codex CLI、Electron、WebView 或常驻查询子进程，无第三方库。

## 安装

打开构建生成的 `CodexPeek.dmg`，将完整的 `CodexPeek.app` 拖到旁边的 `Applications` 文件夹。退出旧版后，从 Finder 的“应用程序”打开新版；不要只复制包内的可执行文件。替换应用不会清除账号别名与窗口设置。

应用默认在菜单栏运行，不在 Dock 常驻。Finder 中的应用应显示专用的绿蓝双进度条图标，可以通过“显示简介”核对应用版本，避免误用旧副本。图标位于应用包的 `Contents/Resources/AppIcon.icns`，构建时会校验签名。

## 构建与运行

需要 macOS 13+、支持 Swift 6.0+ 的 Xcode / Command Line Tools。开发工具链需支持 macOS 13 目标，实际本机验证版本见 [开发说明](docs/development.md)。

```bash
swift run CodexPeekChecks
bash scripts/build-app.sh
open dist/CodexPeek.app
```

也可以双击 `dist/CodexPeek.app`。本地构建只做 ad-hoc 签名，没有 Developer ID 签名和公证；下载到其他 Mac 后可能受到 Gatekeeper 限制。

生成带 Applications 拖拽入口的 DMG 安装包：

```bash
bash scripts/build-dmg.sh
```

结果为 `dist/CodexPeek.dmg`，脚本会校验镜像完整性；构建脚本不会自动安装或启动应用。

默认分别编译 Apple Silicon 与 Intel 后合并为通用二进制；也可以只构建指定架构：

```bash
CODEXPEEK_ARCH=arm64 bash scripts/build-app.sh
CODEXPEEK_ARCH=x86_64 bash scripts/build-app.sh
```

不访问真实账号的演示：

```bash
swift run CodexPeek --demo
```

自愿执行一次真实额度查询的脱敏诊断（退出码 0 表示至少一个账号查询成功）：

```bash
swift run CodexPeek --diagnose
```

## 账号来源

默认只读两个文件，路径可以在详情设置中修改：

| 文件 | 用途 |
| --- | --- |
| `~/.cc-switch/codex-login-stash.json` | 读取 `logins` 中已有的订阅账号授权 |
| `~/.codex/auth.json` | 识别本机当前使用的订阅账号，并合并最新访问令牌 |

不需要专门的切换工具适配器。通过 cc-switch、Magpie 或其他方式切换后，只要它更新这里配置的 Codex 认证文件，就能识别。使用 Keychain 或不同 `CODEX_HOME` 的登录方式，需要提供相应的文件来源；当前不直接读取其他应用的 Keychain。

展示来源中去重后且具有可用登录授权的账号，并合并当前 Codex 登录。当前账号始终排第一，其余按稳定账号 ID 排列；改名不改变顺序。新增、删除或切换账号后自动更新，未登录、授权过期及已确认授权失效的账号自动隐藏；网络失败与临时限流不作为退出登录。旧版的固定账号选择不再限制展示。

## 重要行为

- 百分比表示**剩余量**。缺失窗口显示 `—`，不把缺数据当作额度为零。
- 5 秒是客户端查询目标周期，服务端数据不保证每 5 秒变化；所有账号参与刷新，最多三个并发请求；按到期时间公平调度，账号较多时实际周期可能更长，失败时降低频率。
- 账号文件元信息每秒检查，变化后重读；不扫描其他目录。不完整文件额外重试一次。
- 过期访问令牌不会自动刷新，相应账号会隐藏。请在原工具重新登录或切换以更新授权，文件更新后自动恢复展示。
- 网络失败时保留旧数据并变灰；详情标记为旧数据并显示更新时间。
- 查询直接访问 Codex 使用的内部 HTTPS 用量端点；这不是承诺稳定的公开 API，格式或授权机制变化时可能需要更新应用。
- 不调用模型、不消耗对话 token；查询仍可能受到服务端限流。

窗口默认自动适配账号数量，手动拉伸后保留自选尺寸。窄窗将重置时间置于下一行，拉宽至 500 pt 后在右侧同一行显示。可在详情中点击“恢复自动尺寸”，恢复默认宽度及按账号数增高。
